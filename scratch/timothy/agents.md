# AI Developer Agents Guidelines (Timothy's Scratch Workspace)

Before doing any work in this scratch folder, you MUST adhere to the following workflow:

1. **Design First**: Always start by writing a design document in the `designs/` directory. The
   design document must have the same name as the tool you are planning to build (e.g.,
   `designs/logical_data_filler_v1.md`).
2. **Collaborate & Refine**: Iterate on the design document together with the user, keeping it as
   simple and tailored as possible.
3. **Wait for Approval**: **DO NOT** implement or modify any actual tools, scripts, or application
   code in this scratch folder until the user explicitly says "go" or approves the implementation
   step.
